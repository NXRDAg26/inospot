# Inospot

James Norgate's personal market opportunity app. Every weekday morning a Claude scan researches the markets and publishes ideas, a pick of the day, a morning note, a research watchlist and a catalyst calendar into Inospot, which then sends a push alert to your phone.

Built like Flightdeck: Next.js 14 on Render, Postgres, password sign-in, installable on your phone.

## Screens

- **Today**: pick of the day, market mood, other top ideas, upcoming dates, biggest stories
- **Ideas**: reward-against-risk chart and every idea ranked, with a full page for each
- **Research**: hot themes and a watchlist across shares, funds, bonds and commodities
- **Markets**: the morning note and what moved markets
- **Calendar**: results and policy dates that could move your ideas
- **Alerts**: turn on push alerts for this device, see recent scans

## How data gets in

Inospot exposes a small Claude connector (MCP) at:

```
https://<your-render-url>/api/mcp/<MCP_KEY>
```

Add that URL in Claude as a custom connector named **Inospot**. The morning scheduled task then calls `publish_scan`, which saves the scan and pushes the pick of the day. `get_latest_scan` returns what the app is showing.

Until the first scan is published, the app shows the seed scan in `data/seed.json`.

## Deploy on Render

1. Push this repo to GitHub.
2. In Render: New, Blueprint, pick the repo. `render.yaml` creates the web service and a Postgres database.
3. Fill in the environment variables Render asks for:
   - `APP_PASSWORD`: the password you sign in with
   - `VAPID_PUBLIC_KEY` and `VAPID_PRIVATE_KEY`: for push alerts (generate with `npm run vapid`)
   - `SESSION_SECRET` and `MCP_KEY` are generated by Render automatically
4. Optional: add a custom domain such as `spot.nx-rd.com` in the service settings.
5. Copy `MCP_KEY` from the service's environment and add the connector URL above in Claude.

## Local development

```
npm install
npm run dev
```

With no `APP_PASSWORD` set the app is open; with no `DATABASE_URL` it shows the seed scan.
